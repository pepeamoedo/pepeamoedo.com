# Pepe Amoedo — Technical 3D Artist & Frontend Developer

Bienvenido a mi espacio de trabajo. Soy un desarrollador con formación en **Bellas Artes** radicado en Sevilla. Me dedico a esculpir experiencias interactivas y herramientas visuales escribiendo código a bajo nivel para la web. 

Mi enfoque se centra en exprimir el hardware del navegador (GPU) para crear arte procedimental, simulaciones masivas y arquitecturas modulares eficientes.

### ⚙️ Ecosistema Técnico
- **Gráficos & Shaders:** WebGPU, WGSL, Compute Shaders (GPGPU), SDFs (Signed Distance Fields), Raymarching.
- **Web Frontend:** JavaScript (ES6+), Vite, HTML5 Canvas, Web Audio API.
- **Technical Art:** Blender, Geometry Nodes, NPR (Non-Photorealistic Rendering), Generación procedimental.

### 🚀 Proyectos Destacados

#### 1. [Geometric Temple](enlace-a-tu-repo-o-web)
Un motor de renderizado custom en WebGPU construido desde cero. 
- Transiciones de estado limpias y arquitectura modular.
- Generación de geometría colosal mediante funciones SDF puras en el *Fragment Shader*.
- Diseño sonoro dinámico y reactivo utilizando la *Web Audio API*.

#### 2. [WebGPU Organic Swarm (Compute Shaders)](enlace-a-tu-repo-o-web)
Simulación fluida de alta densidad ejecutada 100% en la tarjeta gráfica.
- Cálculo de +100,000 partículas en paralelo mediante `Storage Buffers`.
- Implementación de *Curl Noise* y campos vectoriales en WGSL para un comportamiento de enjambre orgánico.
- Máximo rendimiento sin bloquear el hilo principal de JavaScript.

#### 3. [NPR (Non-Photorealistic Rendering) Pipeline](enlace-a-tu-repo-o-web)
Arquitectura de múltiples pasadas (*Multi-Pass Rendering*) para simular medios tradicionales.
- Renderizado de escenas a texturas ocultas (Framebuffers).
- Filtros de post-procesado para detección de bordes (Sobel) y tramado estilo grabado (Hatching).
